# Exposed

18+ party web app. Friends join via PIN on their own phones.

## Modes

- **Tea Time** — write a question, gossip, and challenge about another player
- **Spicy Stakes** — curated deck of one-shots, categories, and lasting rules

## Development

```bash
npm install
npm run dev
```

- Client: http://localhost:5173  
- Server: http://localhost:3001  

## Production

```bash
npm run build
npm start
```

The server serves the client build on port 3001.
